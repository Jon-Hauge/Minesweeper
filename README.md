# **🕹️ Minesweeper**

Demo-video: https://youtube.com/watch/2YNduCX3u7c?feature=share

Prosjektet gikk ut på å omforme et fungerende tetris-program
til minesweeper. Dette innebærte hovedsaklig endring av grid
til å passe det nye programmet, innføre klikk-funksjonalitet
og nye klasser for spillogikk.

Regler for spillet er som følger:
Venstre klikk avslører celler, høyre klikk flagger. Treffer man en mine er spillet over, men avslører/flagger man alle cellene uten miner vinner man. Man kan velge mellom easy, medium og hard, noe som avgjør størrelsen på brettet, antall flagg og antall miner.
